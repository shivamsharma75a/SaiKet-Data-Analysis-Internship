# SaiKet Data Analysis Internship

## Author

## Project Overview
This repository contains all tasks completed during the SaiKet Data Analysis Internship using Python, Pandas, NumPy, Matplotlib, Scikit-learn and Google Colab. The project is based on the Telco Customer Churn Dataset.

---

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

---

## Task 1: Data Cleaning & Preprocessing
### Objective
Clean and preprocess the Telco Customer Churn dataset.

### Tasks Performed
- Loaded CSV dataset
- Displayed first 5 rows
- Checked dataset information
- Checked missing values
- Removed duplicate records
- Converted TotalCharges to numeric
- Applied One-Hot Encoding

---

## Task 2: Exploratory Data Analysis (EDA)
### Objective
Analyze the dataset and identify important customer churn patterns.

### Tasks Performed
- Churn Distribution
- Gender Analysis
- Contract Type Analysis
- Payment Method Analysis
- Tenure Analysis

---

## Task 3: Data Visualization
### Objective
Visualize customer data using charts.

### Charts Created
- Histogram
- Bar Chart
- Scatter Plot
- Box Plot

---

## Task 4: Churn Prediction Model
### Objective
Build a Machine Learning model to predict customer churn.

### Algorithm
- Logistic Regression

### Result
- Model Accuracy: **78.25%**

---

## Task 5: Final Insights & Report

### Key Insights
- Customers with month-to-month contracts have higher churn.
- Long-term customers are less likely to churn.
- Higher monthly charges are associated with higher churn.
- Data preprocessing improved model performance.
- Logistic Regression achieved approximately **78%** accuracy.
